# CPU Performance Prediction & Statistical Analysis

A comprehensive data analysis and statistical modeling project developed as part of the Data Analysis course at the Aristotle University of Thessaloniki (AUTH). The project focuses on predicting CPU performance based on hardware technical specifications using various regression techniques and dimensionality reduction methods.

## ✨ Features
- **Data Exploratory Analysis:** Preprocessing and visualization of hardware specifications and multi-dimensional datasets.
- **Regression Modeling:** Implementation of Simple and Multiple Linear Regression models.
- **Feature Selection:** Utilization of Stepwise Regression to identify the most statistically significant predictors and prevent overfitting.
- **Dimensionality Reduction:** Application of Principal Component Analysis (PCA) to reduce feature space while retaining maximum variance.
- **Model Validation & Diagnostics:** Evaluation of model reliability using thorough residual diagnostics (collinearity, homoscedasticity, normality checks) and **10-Fold Cross-Validation**.

## 🛠️ Technologies & Toolboxes Used
- **MATLAB**
- Statistics and Machine Learning Toolbox
- Data Visualization Tools (Residual plots, PCA score plots, variance charts)

## 📊 Methodology & Implementation
1. **Exploratory Data Analysis (EDA):** Checking for outliers, missing values, and analyzing feature correlations.
2. **Dimensionality Reduction:** Applying PCA to compress highly correlated hardware specs into independent principal components.
3. **Model Training:** Fitting multiple linear models and running stepwise algorithms to optimize the feature subset.
4. **Validation:** Testing model generalizability through 10-fold cross-validation and verifying regression assumptions via residual plots.
